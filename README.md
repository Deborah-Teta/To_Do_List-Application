Interactive To-Do List with Drag & Drop

A modern, interactive to-do list application built with React that features drag-and-drop functionality and persistent storage.

Features

- Add Tasks: Create new tasks with a simple input form
- Delete Tasks: Remove tasks with a single click
- Drag & Drop: Move tasks anywhere on the screen
- Persistent Storage: Tasks save automatically and persist after reload
